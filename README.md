# godmonth-topia

JDK 17 工具库：RPC、分页、数据访问、校验与幂等。已发布到 [Maven Central](https://central.sonatype.com/namespace/com.godmonth.topia)。

从 `topia-commons` 迁过来见 [MIGRATION.md](MIGRATION.md)。

```xml
<dependency>
    <groupId>com.godmonth.topia</groupId>
    <artifactId>topia-bom</artifactId>
    <version>1.0.0</version>
    <type>pom</type>
    <scope>import</scope>
</dependency>
```
